# Style Reading

## Purpose

Extract a reusable visual grammar from one or more style exemplars without copying their subject, exact layout, wording, logos, or distinctive branded details. This is analysis, not imitation. Keep style and content separate: the user's source supplies the content; the Style Profile supplies only abstract visual behavior.

## Style Fingerprint

Read each exemplar across the same axes:

- **page topology**: where visual weight gathers, which axes carry movement, and how calm space counterbalances density;
- **photo topology**: whether photography appears as a core, fragments, a field, or a partially converted layer;
- **boundary behavior**: how photographic detail meets paper, ink, wash, abrasion, or overprint;
- **shape language**: geometric versus organic masses, contour character, repetition, and degree of simplification;
- **mark process**: dry line, screen tone, cut fiber, wash, stencil, grain, registration shift, or another visible production logic;
- **color architecture**: paper tone, dominant ink family, supporting tone, signal color, and the job each color performs;
- **detail rhythm**: where fine information, medium-scale structure, and broad quiet fields occur;
- **depth order**: base stock, printed field, photographic core, overprint, and optional type;
- **semantic distance**: how literally the exemplar preserves objects versus translating them into pattern or atmosphere;
- **type relationship**: only the scale, placement logic, and material voice of lettering, never its wording.

For multiple exemplars, keep repeated properties and discard isolated subject-specific accidents. For one exemplar, mark uncertain properties and avoid treating every visible choice as a rule.

## Content-Leak Guard

Do not transfer:

- people, landmarks, objects, symbols, poses, or narrative events from an exemplar;
- exact crop, exact silhouette, exact text placement, titles, credits, signatures, or watermarks;
- a named living artist, protected brand system, or proprietary project identity;
- a one-off decorative motif that is not supported by the user's source.

Translate every retained property into neutral production language. A useful check is: if the exemplar subject were replaced, would this description still make sense? If not, it is content rather than style.

## Direction-Engine Handoff

This document produces the neutral Style Profile only. It does not select a composition, mix processes from competing candidates, or override [direction-engine.md](direction-engine.md). Hand the completed Profile and source morphology to the Direction Engine, which exclusively owns candidate construction, hard gates, selection, runner-up retention, and retry routing.

For auditability, store each Style Fingerprint property with its supporting visual evidence, confidence, stability across exemplars, and exclusions. Do not expose this internal record unless the user asks.

## Prompt Translation

Convert the selected profile into observable instructions. Prefer operational descriptions such as "the dense background band simplifies into broken cool-gray linework while the protected foreground subject stays photographic" over labels such as "artistic" or "zine-like". State where each process occurs, what it connects to, and what must remain quiet.

Never attach benchmark or exemplar result images to `image_gen` merely to imitate them. Analyze them first, then send only the user's authorized edit targets and the abstract Style Profile.
